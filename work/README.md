# LAST SECOND 最后一秒

巨型钟表题材的一指极限逃生网页游戏：化作一粒时间火花，在秒针横扫、钟摆冲击与发条收紧间蓄力冲刺；每轮过后选择收手入账，或赌上未结算分继续冲下一轮。

## 本地运行

**Prerequisites:** Node.js

1. 安装依赖：`npm install`
2. 开发模式：`npm run dev`
3. 构建上线版：`npm run build`（产物在 `dist/`，纯静态站点，无服务端、无需任何 API 密钥）

## 数据与隐私

- 无账号系统，所有记录（成绩、设置、进度）只保存在浏览器本地 localStorage。
- 不接入任何第三方统计、广告或登录 SDK；内置的统计只是本地控制台日志，不联网。
- 游戏内「免费复活一次」是内置功能，不播放广告、不收费。

## 部署提示

- 部署到 Vercel：构建命令 `npm run build`，输出目录 `dist`（`vercel.json` 已配好，含基础安全响应头）。
- 上线后把 `index.html` 里分享封面的 `YOUR_DOMAIN` 换成正式域名（微信/微博/X 等平台要求 PNG + 完整网址）。
